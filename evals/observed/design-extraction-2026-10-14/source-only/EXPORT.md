# Public example export

This is an allowlisted public subset of the original source-only exercise. The
synthetic inputs and generated token/profile/HTML artifacts are copied unchanged.
REPORT.md and DESIGN.md are explicitly redacted public copies: unrelated receiving-
project adoption details were replaced with portable scope notes. Original hashes
remain in original-artifact-hashes.json; original complete reports remain local.
Captured instruction Markdown bytes use a .txt suffix so their original relative
links remain historical input data, not broken live documentation.
Unrelated TCSN project instruction copies were withheld. The instruction index and
capture-context metadata are filtered replacements with original hashes; SHA256SUMS
covers this public subset. The original complete run remains in the local temporary
workspace and its original validation results describe that complete run.

No model/browser task was rerun to produce this export. Root-level evaluation
records separately describe independent review and native host loading. The local
candidate token format in this exercise is explicitly not DTCG; a separate focused
exercise checks DTCG export. These are not canonical behavior-case executions.
